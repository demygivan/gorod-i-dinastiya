# Город и Династия — стартовый скелет (Godot 4 + Cursor)

## Как открыть

1. **Godot:** Godot Engine 4.3+ → "Import" → выбери эту папку → Play.
   В `GameState` уже будет тестовая семья/персонаж/ферма, нанятая через
   `HireWorkerCommand` (см. `world/main.gd`).
2. **Cursor:** открой эту же папку как проект. `.cursor/rules/godot-architecture.mdc`
   подключается автоматически на каждый твой запрос (это инструкция, не сама
   спека) и говорит агенту: для задач по геймдизайну/механикам/архитектуре —
   сначала открыть и прочитать `docs/GAME_SPEC.md`; для мелких правок
   (опечатка, форматирование, явный баг) — не открывать, чтобы не тратить
   контекст впустую. Ты **ничего не прикрепляешь руками**.
   (Работает именно в Agent/Composer-режиме, где у модели есть доступ к
   файловой системе; в обычном Chat без файловых инструментов файл всё же
   надо прикреплять вручную.)

## Единственный файл, который редактируешь ты

`docs/GAME_SPEC.md` — вся геймдизайн-часть (классы, навыки, здания, город)
+ архитектурный контракт, включая раздел про готовность к мультиплееру
(§9 — что можно/нельзя делать до отдельного multiplayer-ТЗ). Дорабатывай
его по мере продумывания механик, разделы 8-9 не трогай без явного решения.

## Структура кода одной строкой

`core/data` = состояние, `core/commands` = как его менять, `core/systems`
= что происходит само по времени, `world`/`ui` = картинка, `autoloads`
= глобальные синглтоны (GameClock/GameState/EventBus).
