> и `data/city/coastal_river_layout.txt`. Не открывай `GAME_SPEC.md` ради мелких правок карты.

## Символы (1 символ = 1 тайл 32×32)

| Символ | Слой / смысл | Слот |
|--------|--------------|------|
| `.` | Земля (ground) | — |
| `#` | Дорога (road_layer) | — |
| `+` | Перекрёсток (как дорога, вес AStar 1.0) | — |
| `=` | Мост (road_layer, проходим) | — |
| `~` | Вода (water_layer) | — |
| `P` | Площадь (plaza_layer) | — |
| `F` | Поля (farmland, жёлтый тайл) | — |
| `T` | Лес (forest, тёмно-зелёный тайл) | — |
| `A` | Парк (газон, проходим, вес AStar 1.0) | — |
| `H` | Ратуша | `town_hall` (фикс.) |
| `S` | Производство (лавка / мастерская) | `commercial_x_y` |
| `D` | Порт / морская торговля | `maritime_x_y` |
| `R` | Дом жителя | `residential_x_y` |
| `M` | Рыбак | `fisherman_x_y` |
| `B` | Бандит | `bandit_x_y` |
| `G` | Главные ворота | `gate_main` |
| `C` | Кладбище | `cemetery_x_y` (фикс.) |
| пробел / другое | Пусто (unknown) | — |

## Вода: река vs море vs озеро

Парсер (`CityLayoutParser._classify_water`):

1. Строки, где **≥50%** клеток `~`, считаются «морскими рядами».
2. От всех `~` в таких рядах — flood-fill → **море** (`sea`).
3. Остальные `~` → **река / озеро** (`river`). Озеро слева не соединено с морем, поэтому остаётся `river`.

**Правило для редактора:** низ карты — сплошное или почти сплошное `~` (залив/море).
Река — узкая полоса `~` справа, к морю. Озеро — эллипс `~` слева от стен. Мост `=` ставится **на дороге** поверх `~`.

## Текущий дизайн (40×30, 2D top-down)

Компактная ортогональная сетка (Square, не изометрия):

```
[ лес T / парк A слева сверху ] [ поля F сверху ] [ сетка улиц S, ратуша H ] [ река ~~ / мосты = ] [ лес T, бандит B ]
                [ озеро ~~~, рыбак M ]
                [ жилой квартал R слева снизу ]
         [ море ~~~, причалы D ]
```

- **Северо-запад:** парк `A` (газон 10×5), тонкая полоса леса `T` по левому краю; южный край парка стыкуется с дорогой.
- **Запад:** лес `T` по левому краю ниже парка, озеро и слот рыбака `M`.
- **Север:** поля `F` над городом, справа от парка.
- **Центр:** улицы каждые 3 тайла. **Производственные** здания `S` (мастерские, лавки) сразу к югу от дороги, ратуша `H` на главной оси.
- **Юго-запад:** жилой квартал — только **дома** `R`, свои улицы, стык с городом на y=20/23.
- **Восток:** узкая река `~` с мостами `=`, кладбище `C` у набережной, за рекой лес `T` и слот бандита `B`.
- **Юг:** причалы `D` и море.
- TileMapLayer / `slots` / `Buildings` — Y-Sort Enabled.
- Случайный пул отключён; на слотах рисуются заглушки по `slot_kind` (`CoastalCityMap._spawn_placed_buildings`).

## Слоты зданий

Каждый символ `S` / `R` / `D` / `C` / `M` / `B` — **якорь** участка 2×2 тайла (64×64 px).
Два игровых типа застройки:

| Тип | Символы | Визуал-заглушка |
|-----|---------|-----------------|
| Дом | `R` | `house` (тёплый коричневый) |
| Производство | `S`, `D`, `M` | `workshop` (серо-кирпичный) |

Ратуша `H`, кладбище `C`, бандит `B` — civic / особые, не жильё и не цех.
Категория пула: `BuildingSpawnEntry.get_category()` → `house` / `production` / `civic`.
Якорь стоит на земле **в следующей клетке после дороги** (не на самой `#`).
Участок целиком на земле, северным краем **вплотную к улице**, без наложений на
`#` / `=` / `~`. Маркер и визуал стоят в центре участка, не в центре якоря.

`H` — ратуша 3×3 (96×96 px) на перекрёстке главной улицы; единственное здание другого размера.
`C` у реки, восточнее ратуши — **кладбище, всегда фиксировано**. `G` — ворота, без здания.

Между двумя 2×2 вдоль улицы — 1 тайл земли. Визуальный inset в `placed_building_view.gd`
маленький (⅛ слота), чтобы фасад стоял у края дороги. Северные подходы без домов.

## Каталог зданий

Файл: `data/city/production_buildings.tres`

Для генерации берётся поле **Building** (`id` в snake_case). Сначала ставится
`minimum_quantity` каждого типа на подходящий `slot_kind`, затем оставшиеся слоты
заполняются weighted random (`weight` = Probability из таблицы).

| Group | Типичный slot_kind |
|-------|-------------------|
| Patron / Craftsman / Scholar / Rogue | `commercial`, часть `residential` / `maritime` |
| Infrastructure (min 0) | `residential` / `commercial` — заполняет остаток |
| Cemetery | только слот `C` |
| Town Hall | только слот `H` (не в random-пуле) |

Логика: `CityLayoutAssigner.assign(slots, pool, seed)` → `slot_id → Assignment`.
Пекарня игрока по-прежнему занимает первый commercial-слот.

Визуал после rebuild: `CoastalCityMap._spawn_placed_buildings()` — **сейчас только чистит `Buildings`**, assigner отключён.

Перегенерация каталога:

```bash
python tools/generate_production_buildings.py
```

## Коллизии и навигация

- Непроходимые тайлы: вода `~`, лес `T`, весь footprint зданий (`R`/`S`/`H`/`D`/`C`/`M`/`B`, 2×2 или 3×3 у ратуши). Ворота `G` и парк `A` проходимы.
- Физика: полигоны в `CityPlaceholderTileset` (вода, лес, невидимый `COLLISION`); footprint красится на `obstacle_layer`. `PlacedBuildingView` — `StaticBody2D`.
- AStar: `core/systems/city_navigation_system.gd`. Дороги `#`/`+`/`=` вес 1.0, парк `A` и площадь `P` вес 1.0, земля/поля `.`/`F` вес 10.0. Днём NPC ходят между дверями производственных зданий и парком, не по жилым улицам.

## Rebuild в редакторе

1. Открыть `world/coastal_city_map.tscn`.
2. В инспекторе на root → **Rebuild From Layout** (или `auto_build_on_ready` при запуске).
3. Камера центрируется автоматически; pan — СКМ / WASD, zoom — колёсико.

## Что карта **не** делает (пока)

- Не создаёт BusinessState для всех визуальных зданий (только типы с `business_type_id`).
- Позиции NPC-визитов берутся из слотов с `business_type_id` (`coastal_city_map.gd`).

## Перегенерация черновика карты

```bash
python tools/generate_coastal_layout.py
```

Скрипт перезаписывает `coastal_river_layout.txt`. После правок вручную — правь `.txt` напрямую.
