# System specifications

Create one focused file per system, for example:

- `economy_core_v1.md`
- `bakery_mvp.md`
- `npc_demand_v1.md`
- `reputation_v1.md`
- `politics_v1.md`
- `save_load_v1.md`
- `localization_v1.md`

Each specification should state: purpose, authoritative state, commands, validation rules, emitted events, UI requirements, edge cases, and acceptance tests.
